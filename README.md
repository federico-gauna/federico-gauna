## Proyectos destacados

### [Comercio Electrónico — API REST](https://github.com/federico-gauna/comercio-electronico-api)

API REST desarrollada con Java y Spring Boot para gestionar productos, categorías, clientes y pedidos.

Incluye persistencia con PostgreSQL y JPA/Hibernate, autenticación JWT, autorización por roles, validaciones y documentación con Swagger/OpenAPI.

**Tecnologías:** Java 21 · Spring Boot · PostgreSQL · Spring Security · JWT

### [Motor de Cotización de Seguros](https://github.com/federico-gauna/cotizador-seguros)

Motor de reglas de negocio para calcular cotizaciones de seguros de vehículos según diferentes condiciones y factores de riesgo.

Implementa un diseño extensible mediante interfaces y composición de reglas, acompañado de 41 pruebas automatizadas con JUnit 5.

**Tecnologías:** Java 21 · Spring Boot · JUnit 5 · POO

### [Base de Datos Relacional de eSports](https://github.com/federico-gauna/eSports-Relational-Database-MySQL)

Diseño e implementación de una base de datos relacional para representar competiciones de eSports, contemplando diferentes modalidades de juego, participantes, equipos y torneos.

El proyecto aborda desafíos de modelado, relaciones entre entidades, normalización y consultas SQL.

**Tecnologías:** MySQL · SQL · MySQL Workbench
